# 需求与咨询：首版使用与更新

这一版将市场入口改为「需求与咨询」，复用现有账号、Cloudflare D1 和 AI 配置。新增记录保存在原 records 表中，不需要新建数据库或重新导入旧数据库，不要更换 VAULT_KEY。

借鉴 [OpenMagpie](https://github.com/obris-dev/openmagpie) 的语义筛选与可审查记录思路；没有安装其整套服务或复制源码。这个小版本只处理你有权使用的去标识化文字，暂未连接小黑盒。授权后才评估 heybox-cli 的搜索、帖子、评论读取效果与稳定性。

## 用四条示例验证流程

1. 登录后打开「需求与咨询」，点击明确标为「示例」的导入按钮。这些是合成样本，不是真实客户。
2. 对其中一条点击「AI 分析」。调用的是「设置 → AI」中的模型和密钥，与学习助手共用每日请求次数和估算预算；导入和浏览不会自动调用 AI。
3. 查看类别、理由和原文证据。服务器要求证据逐字出自导入文本，AI 回复是未发送草稿。
4. 按实际判断选择人工通过或忽略，再手动设置参考类别。页面只统计已分析且有参考类别的样本，显示样本量与一致率；不代表真实获客准确率。

建议再用 10–20 条自己确认有权使用、已去除个人信息的真实问题测试。先人工标注，再分析；重点检查「已经解决」「不需要」「广告」是否被误当作需求。结果不够好时先调整分析提示和类别，不急于自动采集。

单条文本最多 4000 字，每次批量 JSON 导入最多 20 条。导入要确认授权和去标识化。明显邮箱、大陆手机号码和银行卡号会被拒绝；检测不涵盖所有个人信息，提交前仍需人工检查。来源链接只能使用无账号密码、无查询参数的 HTTP/HTTPS 地址，系统不访问这些链接。

相同规范化文本和来源链接会复用原记录，返回新增和重复数量。编辑原文或来源链接会清除旧分析；分析期间修改文本会拒绝保存过时结果。咨询记录只能手动录入已自愿提出的问题，记录处理状态与备注，不要求联系方式。

## 这一版的取舍

- 自动评论、私信、发帖和爬取都未启用。需求分析通过人工审核后，由你决定是否以及怎样回应。
- 使用说明中的教程内容只提供可核查的来源与审核提示，不自动发布金融产品推广或承诺订阅成功。
- [Roogoo 官方 FAQ](https://help.roogoo.com/zh-CN/articles/11659674-roogoo-card-%E7%A4%BE%E5%8C%BA%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98-%E7%94%A8%E5%8D%A1%E6%8C%87%E5%8D%97) 说明预付卡及 USDT 充值，也提示订阅失败风险、不能保证成功。不同卡种条件可能不同，费用与支持范围要以当时官方页面为准，免费教程不等于办卡或支付无费用。
- AI 分类和置信度属于模型判断，需要核对上下文。原文证据验证只能防止凭空引用，不保证结论正确。

## 上传 GitHub 和 Cloudflare

将新的源码 ZIP 解压，上传解压后根目录的源码到**现有 GitHub 仓库**，不要只上传 ZIP。根目录应直接看到 package.json、wrangler.jsonc、src、functions、cloudflare、server 等。

这是更新已有网站：Cloudflare Pages 项目仍用 `moya`，生产分支仍用原分支，构建命令保持 `npm run build`，输出目录保持 `dist`，已有 DB/VAULT_KEY/APP_ORIGIN 设置保持原值。提交 GitHub 后，Pages 自动构建 Functions 并发布；查看最新部署的成功状态，再刷新 moyaiwork.com。

**不需要把任何数据库或密钥上传 GitHub，也不需要重新导入 data.sql。** 源码包排除了 .env、SQLite、vault.key、私人导出和 node_modules。通过 GitHub 连接部署时，也不需要手动将 dist 上传 Cloudflare。

后续修改：修改自己的源码 → 本地测试与 `npm run build` → 提交同一个 GitHub 仓库 → 检查 Pages 最新部署。电脑关机后，Cloudflare 上的网站、已保存的记录和网页 AI 调用仍可用；本版本没有后台定时采集任务，本机 Codex 同步助手仍取决于运行它的电脑或服务器。

验证命令：`node --test tests/demand-contracts.test.mjs`、原服务器/Cloudflare测试、`npm run test:ui`、`npm run build`。Cloudflare 原生打包与真正云端发布的状态另见交付验证记录，不能用前端构建成功代替云端验证。
