# 英语学习中心

学习中心默认展示今日学习、单词训练、语境阅读、逐句听写和复习计划。右上角“AI 助手与学习计划”可以进入原来的 AI 辅导、目标、专注计时及错题功能。

## 练习方法

1. 单词：从入门练习包开始，键入单词并检查；答对后加入今日进度与复习计划，也可手动收藏。听音模式需主动点击播放。
2. 阅读：点击标线词查看释义和原文语境，收藏后会保留遇见它的句子；读完可标记已读。未标线词暂不含离线释义。
3. 听写：播放一个句子，可暂停、重播及调速；提交后查看错词、漏词和多词。词级准确率忽略大小写与标点，不是口语评分。
4. 复习：先回忆再翻答案，按真实记忆程度选择“忘记了 / 有点难 / 记住了 / 很轻松”。服务器使用 ts-fsrs 5.4.2 计算并保存下次时间。

## 账号与保存

实际登录后，练习结果通过同源登录会话保存到当前工作台数据库，手机与电脑共用；提交中与失败状态会明确显示。另一台设备已更新时，需要刷新并重新检查，不会用旧状态覆盖新进度。遇到网络中断，可以重试同一次操作，不会重复计入。

初次打开没有虚构的学习数据。原型中的本地 localStorage 记录不自动导入正式账号。演示模式不会调用真实学习接口或写入账号。

复习记录可从学习中心导出独立 JSON 备份。当前独立导出用于保留原始学习状态，不含密码、API 密钥或工作台其它数据；界面暂未提供该文件的导入功能。设置页的旧业务记录备份不包含此独立英语状态，完整服务器数据库备份会包含它。

## 材料与边界

当前是 12 词、一篇原创短文和 3 句合成语音的入门练习包，尚不是完整四六级或考研资料库。释义仅覆盖包内词汇；语音不是考试真题录音。新功能不调用付费 AI；原 AI 学习助手仍按你配置的服务商及用量限制调用。

FSRS 当前采用默认参数与 90% 目标保留率；目标值不是记忆效果保证，也未进行个性化参数训练。

为控制轻量数据库的体积，当前保留最近 366 个有学习活动的日期、最近 200 条复习日志，以及最近 500 次操作的安全重试凭据。词卡与下次复习时间持续保留。导出文件反映此保留范围，不是无限期的逐次日志归档。

## 后续维护

- `shared/english-data.mjs`：原创词条、文章、译文及句子，配套 `.d.mts` 提供类型。
- `public/english/audio/`：按需加载的音频文件。
- `src/components/english-center.tsx` / `.css`：界面。
- `src/lib/english.ts`：客户端数据交互与显示辅助。
- `server/english-study.mjs`：校验、记录和调度；本地与 Cloudflare 使用相同实现。

更改后执行 `npm test` 和 `npm run cloudflare:build`，推送原仓库 main 分支触发原 Pages 项目自动发布。新增材料时保持已有词条 ID，避免已有复习记录失去对应材料。
