# 小黑盒后台：模拟测试版

2026-10-13。范围为用户已确认的中文深色管理界面与浏览器内模拟流程，不连接小黑盒真实账号，不发送评论、关注或私信。

## 使用

工作台导航选择「小黑盒后台」→「流程控制台」。原有需求、人工 AI 分析和自愿咨询保留在「原有需求与咨询」，原数据库、密钥、模型配置和同步助手未修改。

1. 默认「异常重试」场景，点击开始测试。
2. 查看流程进度、当前测试对象、回帖/关注/私信状态。暂停后不再推进，继续从原位置运行。
3. 用户 D 的首次模拟私信会失败并停止。点击「重试失败步骤」，不重复已完成的回帖与关注。
4. 完成后为 2 个完成、2 个忽略、2 条模拟私信、1 次模拟关注。真实发送量始终为 0。
5. 重置后选择「正常流程」，可以验证不注入异常的完整流程。运行中须暂停后重置。
6. 点击用户的「查看」核对样本、模拟草稿及请求对象，日志可筛选全部、私信与异常。

所有用户、请求、审核结果、发送回执都是预设合成数据。需求判断使用测试规则，不调用大模型，也不用于证明真实用户同意或平台许可。当前模拟结果只在组件内存保存；离开控制台、退出登录或刷新会停止并清空，不是服务器后台服务。

## 验证边界

该版本可以验证应用内部界面与状态推进，不验证真实平台的登录、读取、评论、关注、私信接口和消息送达。真实连接仍需另行确认允许方式并进行独立测试。不会实现审核、验证码或反作弊规避。

单文件离线 HTML 为额外交付预览，内嵌脚本和样式，可在 Chrome/Edge 打开，不需要后端。它只包含模拟控制台，不读取原有账户或数据库。Codex 内置浏览器禁止 file: 协议，因而该文件未在内置浏览器中直接打开验证；实际工作台界面与模拟流程已通过 localhost 浏览器检查。
