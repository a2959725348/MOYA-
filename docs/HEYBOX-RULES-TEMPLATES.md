# 任务规则与回复模板设置

2026-10-13，模拟测试版第二版。本次未修改后端、数据库、密钥或同步助手；未推送或部署生产站点。

## 使用步骤

1. 「小黑盒后台 → 任务规则」：选择全部合成样本、指定话题或指定帖子链接。
2. 编辑主题关键词、需求表达和排除条件。支持换行、逗号或分号。主题组与需求组之间是 AND，每组内是 OR；排除条件优先。主题检查标题和评论，需求及排除词只检查评论。此处是字面规则，不使用 AI 语义判断。
3. 「回复模板」：编辑公开回复、教程私信和联系方式三个模板，选填你的教程链接和你自己的联系方式。
4. 右侧选择 A～D 检查当前表单的匹配和草稿。预览不是发送，也不是授权判断。
5. 点击「保存并应用到新测试」。此操作重置模拟进度和日志。运行中先暂停；有未保存修改时不能开始新测试。
6. 返回「流程监控」，选择正常流程或异常重试并开始。测试实际使用保存的规则和模板，而不是只展示配置。

## 搜索范围与变量

指定话题使用完整名称匹配，样本话题为 AI 工具、订阅问答、游戏交流。

指定帖子每行一个，最多 20 个。示例：`https://example.invalid/heybox/post/1001` 为 A、1002 为 B、1003 为 C、1004 为 D。真实帖子链接不会自动抓取；本次没有添加小黑盒采集接口。

变量：`{{用户}}`、`{{关键词}}`、`{{教程链接}}`、`{{联系方式}}`。填写未知变量将拒绝保存。联系方式变量只允许在独立联系方式模板中使用；禁止把已配置联系值放进公开回复、教程段落或教程链接。渲染后也会检查已配置联系值。

教程私信要求样本向当前账号明确请求私信。联系方式另要求样本明确请求联系方式且配置非空，不能由关注或回关替代。本版 A 请求教程并允许关注，但未请求联系方式；D 同时请求教程和联系方式。条件都是合成测试数据，不代表真实授权。

## 保存位置

设置保存在当前浏览器当前站点的 localStorage，键为 `workbench.heybox.simulation.settings.v1`。不写入工作台数据库，不随账号跨设备同步，不做加密凭据存储；请勿填写密码、API 密钥或其他人的联系信息。

浏览器禁止存储时，设置仍可以在本页应用，页面会提示不能持久保存。损坏、旧版本或无效设置会安全回退默认值并提示。刷新会保留有效设置，但清空模拟日志和进度；模拟后台内的分区切换不会停止正在运行的模拟。

「填入默认设置」只是填表，点击保存后才覆盖浏览器设置。全部样本不匹配时，结果显示筛选结束、全部忽略；不会声称互动流程已经执行。

旧版 `HEYBOX-CONSOLE-TEST.md` 中固定完成数量仅适用于默认规则；自定义规则改变完成和忽略数量。

## 验证

`npm run test:ui` 与 `npm run build`。覆盖规则 AND/OR、话题/帖子范围、排除、模板替换、配置快照、明确请求条件、联系值经变量传入的阻止、损坏及禁止存储的降级。实际平台接口和真实发送均不属于本次验证范围。
