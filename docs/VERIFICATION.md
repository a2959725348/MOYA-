## 浏览器与实际 HTTP

在内置浏览器中检查了演示与独立验收账户。电脑视口 1440×1040；手机视口 390×844，实际内容宽度 375（含滚动条），检查过总览、额度、行情、设置、学习中心和任务页面，未出现全页横向溢出。没有真实手机硬件或 Safari 测试，因此这是浏览器视口验收。

完成的实际交互：

- 登录独立账户，未配置数据清楚显示未知 / 等待连接。
- 新增学习目标，修改并保存目标日期，再次打开显示同一北京时间日期。
- 保存昵称，在侧边栏立即显示，并在重新打开页面后保留。
- 导入同平台 ID 两项任务，合并为一项并显示末项标题，保留前项课程和截止时间。
- 标记任务完成、筛选已完成记录；修复后通过真实 HTTP 复验课程、类型与截止时间不被 PATCH 清空。
- 启动并保存专注计时，生成实际学习记录。
- 在另一测试会话撤销原会话后，原浏览器退出操作能够返回登录界面。

- **付费 AI 与行情：** 没有用户配置的真实密钥，未调用付费模型。DeepSeek、OpenAI Costs、Alpaca、Tushare 适配器通过真实接口格式 fixture 验证；真实账号权限、服务商延迟和模型可用性需配置后验证。
- **学习通：** 自动读取任务列表尚未在真实登录会话验证。已提供手动记录、JSON 导入与助手任务上传；不声称自动抓取已启用。
- **实时范围：** 本版以服务器集中采样、网页每 30 秒读状态实现监控，不是逐笔 WebSocket 推送。交易时段若数据源没有提供，显示“来源未提供”；本版没有独立节假日交易日历。
- **部署：** 提供 Docker、反向代理、HTTPS、数据卷配置；机器未安装 Docker，本轮未运行容器、未购买服务器或域名、未发布公网网站。
