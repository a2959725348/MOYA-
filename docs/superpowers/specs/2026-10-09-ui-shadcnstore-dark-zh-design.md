# 工作台界面改造：ShadcnStore 风格、默认深色、简体中文

用户已在 2026-10-09 确认：“选 A，默认深色，语言为 Chinese，确认改造并部署”。A 为 https://github.com/shadcnstore/shadcn-dashboard-landing-template ，以其 Vite 版本的简洁侧边栏、卡片、信息层次和主题设计为视觉参考。

## 范围和设计

沿用 React/Vite、现有 API、登录与 Cloudflare Pages/D1，改造登录页、应用外框、总览、额度、学习、任务、需求与咨询、设置。用近黑背景、低对比边框、蓝紫强调色和统一文字/间距替代现有过小字号与装饰性欢迎横幅。功能信息优先：首页直接展示额度、今日学习和待办，空数据诚实显示，不生成虚构记录。深色与浅色均完整可用。

所有应用自有导航、标题、说明、空态和操作文案使用简体中文。保留产品名、模型标识、API、Codex、网址、用户内容等必须的原文。页面根语言保持 zh-CN。首次加载默认深色，包括登录/启动屏；用户手动选择浅色后重载也保持浅色。失效的存储值归为深色；存储不可用时界面仍可进入与切换。采用 workbench-theme 原有键，初始化在首帧前应用，避免闪白。

桌面侧边栏提供真实可用的收起/展开；手机改为抽屉，选中页面即关闭。中文可读的 13–15px 正文、清晰的指标数字、44px 手机操作目标。320/390/768/1440px 宽度兼容，不出现页面横向溢出；宽表格可在局部滚动。键盘焦点、可访问按钮名称、减少动效偏好保留。无需新增外部字体、图片、图标 CDN、远程运行时资源或 UI 依赖。

## 边界与验收

不改后端、数据 schema、API 设置、支付请求、导入/备份内容、同步助手逻辑。现有任务 CRUD、学习 AI/计时、需求分析/人工审核及咨询同意校验保持其行为。设置表单的模型/密钥保存语义保持。界面显示的主题或同步状态只能由真实状态决定。

主题行为用真实导出函数做先失败后通过的测试；纯排版通过浏览器截图与尺寸/交互检查验证。跑现有 UI 测试和生产构建，再做桌面/手机导航、主题持久化、模态框、所有功能页的浏览器检查。记录截图为合成演示数据，不以其为云端真实业务验证。

保留所借用源码的 MIT 版权/许可；如仅参考设计，自有实现也记录来源。将源码提交至既有 GitHub 仓库主分支，使用现有自动部署；发布后检查确切提交的 Pages 结果、健康接口、登录状态接口和新版资源。凭据不可用时在已验证提交准备好后，只请用户执行最后一条推送命令。
